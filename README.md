# 📝 Redux Toolkit — Todo App

Ushbu loyiha **Redux Toolkit** yordamida vazifalarni (Todo) to'liq boshqarish amaliyoti: vazifa qo'shish, bajarilgan deb belgilash, o'chirish va holatini saqlash.

## 🚀 Texnologiyalar

- **React 19**
- **Redux Toolkit (`createSlice`)**
- **React-Redux**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Vite**

## 📦 Imkoniyatlari

- Yangi vazifa qo'shish
- Vazifani bajarilgan (completed) deb belgilash
- Vazifani ro'yxatdan o'chirish
- Asinxron yuklanish holatlari (loading/error)

## 💻 Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dev rejimida ishga tushirish
npm run dev

# Production uchun build qilish
npm run build
```
